Design kits your AI agent can follow

Verdigris

You don't need to learn the kit's markup. Say what the site should do, and an AI coding agent picks the components, writes the code and checks it against the rules. Turn the controls at the bottom of the screen to see this page in each kit.

How it works

Not a library of components to copy and paste. A set of rules, and an agent that follows them.

Most UI kits hand you finished code and leave the judgment to you. These kits hand the judgment to your agent: what each color is for, which weights to use, where a rule goes, and when not to add anything at all. You pick the look; the agent does the work and checks it.

  1. 01Pick a kitOne look, start to finish: tokens for light and dark, type, layout and every component.
  2. 02Hand it to your agentCopy the kit into your project and point your agent at its DESIGN.md and AGENTS.md.
  3. 03Check the resultEach kit comes with accessibility tests for both themes, so you check the work, not just trust it.
